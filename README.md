### 📂 Featured Projects

#### 🚛 [LoadBridge — Local Truck-Load & Spare-Capacity Platform](https://github.com/rahulhadole6392/loadbridge-platform)
> **Overview:** An industrial-grade freight capacity matching engine and coordination platform tailored for intra-corridor logistics along the Pune — Mumbai Industrial Highway Corridor.
- **Stack:** Python, FastAPI, SQLModel, SQLite, React (Vite), Tailwind CSS, Pytest
- **Key Features:** Deterministic 4-rule matching engine (ordered corridor stops, time overlap, dual weight/volume capacity, cargo suitability), calibrated 0–99% fit-score ranking, idempotent booking confirmations, pre-departure cancellation capacity restoration, and unmasked digital coordination passes.

#### 🚄 [AI-Powered Automatic Block Planning for Train Operations](https://github.com/rahulhadole6392/sih-block-planning)
> **Problem Statement (SIH26027):** Minimizing operational disruption on Indian Railways by optimizing maintenance block allocations.
- **Role & Team:** Team ByteForge | Smart India Hackathon 2026
- **Stack:** Python, Heuristic Scheduling Algorithms, Relational Database
- **Overview:** Engineered an algorithmic decision-support model designed to consolidate civil, electrical, and signaling maintenance windows to increase rail asset availability.
